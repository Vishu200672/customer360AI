# 🧠 Customer360 AI -- Production Machine Learning Engine

Customer360 AI is an end-to-end Machine Learning intelligence engine built for enterprise customer relationship management. It unifies RFM feature engineering, customer segmentation (K-Means), customer churn prediction (XGBoost), purchase propensity modeling (XGBoost), Customer Lifetime Value (CLV) regression, SHAP explainability attributions, and a rules-backed Next Best Action (NBA) decision engine.
